# Security

Recite is a local-first app. Please do not paste private selected text, clipboard text, generated audio, or reading history into public issues.

## Supported Version

Recite is pre-1.0. Security fixes should target `main`.

## Reporting A Problem

Open a GitHub issue with:

- What happened
- macOS version
- Mac model
- Recite version or commit
- Steps to reproduce

Use placeholder text if the original selected text was private.
