# Security

Recite is a local-first app. Do not paste private selected text, clipboard text, generated audio, or reading history into public discussion.

## Supported Version

Recite is pre-1.0. Security fixes should target `main`.

## Report a Vulnerability Privately

Report security issues only through GitHub Security Advisories. Do not open a public issue, pull request, or discussion for a vulnerability.

Use [Report a vulnerability](https://github.com/r3dbars/recite/security/advisories/new) and include:

- Affected Recite version or commit
- macOS version and Mac model
- Impact
- Reproduction steps, with placeholder text instead of private content

## Enable Private Reporting (Maintainers)

Private reporting has to be turned on for the repository:

1. Open the Recite repo on GitHub.
2. Go to **Settings → Code security**.
3. Enable **Private vulnerability reporting**.
4. Confirm the Security tab shows **Advisories** and **Report a vulnerability**.

Draft and publish fixes through GitHub Security Advisories. Do not ask reporters to file public security issues.
